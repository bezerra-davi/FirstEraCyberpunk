### Sobre

Pygma forest é um jogo RPG com narrativa que pode ser jogado apenas com o navegador usando o nodejs.

### Como executar

Para executar o jogo é necessario instalar o node js disponível em https://nodejs.org/en/download

Baixe o arquivo zip, extraia e copie o endereço da pasta dos arquivos do jogo.

No terminal use o comando: (coloca o terminal para executar o comando na pasta do jogo)

```powershell
cd <endereço>
``` 
para executar o projeto então use o comando:

```powershell
node main.js
```

Tenha uma ótima experiência
