# Pygma Forest

## Sobre

**Pygma Forest** é um RPG narrativo jogado pelo terminal utilizando **Node.js**. O jogo combina exploração, combate por turnos e escolhas que influenciam o progresso da aventura.

## Mecânicas

### Combate por turnos

O sistema de combate utiliza os seguintes atributos:

* Vida
* Energia
* Ataque
* Defesa
* Velocidade

### O jogador pode:

* Atacar
* Utilizar habilidades
* Defender-se
* Utilizar itens

## Como executar no Linux

### 1. Abra o terminal

### 2. Instale o Node.js

```bash
sudo apt update
sudo apt install nodejs npm
```

### 3. Baixe o jogo

```bash
git clone https://github.com/bezerra-davi/PygmaForest
cd PygmaForest
```

### 4. Execute o jogo

```bash
node main.js
```

## Atualizando o jogo

Para atualizar para a versão mais recente:

```bash
git pull
```

## Observações

* Não é necessário executar `git clone` toda vez que quiser jogar.
* Antes de usar `git pull` ou `node main.js`, certifique-se de estar dentro da pasta do projeto.
* O jogo foi desenvolvido para ser executado pelo terminal utilizando Node.js.

# WINDOWS

### Como executar

Para executar o jogo é necessario instalar o node js disponível em https://nodejs.org/en/download

Baixe o arquivo zip, extraia e copie o endereço da pasta dos arquivos do jogo.

No terminal use o comando: (coloca o terminal para executar o comando na pasta do jogo)

```powershell
cd <endereço>
``` 
para executar o projeto então use o comando:

```powershell
node main.js
```

Tenha uma ótima experiência
